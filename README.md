# Scotland Business Guide (`scotlandbusinessguide.com`)

Independent Scottish business support directory highlighting 100% free public mentoring and support first, alongside verified hubs, food and drink innovation, FSB Scotland, women's networks, Asian business chambers, student enterprise, and Connectd affiliate referral links with disclosures.

## Repository Structure
- `index.html`: Main application shell, navigation, affiliate links, and structured JSON-LD container
- `assets/styles.css`: Visual styling and responsive layout
- `assets/app.js`: Multi-view router, search and region filters, interactive Scotland regional guide, SEO/GEO updates, and cookie consent logic
- `sitemap.xml`: XML sitemap for `https://scotlandbusinessguide.com/`
- `robots.txt`: Search engine crawler directives
- `llms.txt`: LLM/GEO summary file for `https://scotlandbusinessguide.com/`
- `.github/workflows/deploy-pages.yml`: GitHub Actions workflow to publish static files to GitHub Pages
